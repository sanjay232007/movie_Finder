# Movie Finder

A movie discovery application built using React and Vite.

Browse and search for movies using the TMDB API.

## Features

- Search for movies.
- Browse trending movies.
- Discover movies using the TMDB API.

## Tech Stack

- React
- Vite
- JavaScript
- TMDB API

## Getting Started

Install dependencies:

```bash
npm install
```

Create a `.env` file in the project root and configure your TMDB API key:

```env
VITE_TMDB_API_KEY=your_tmdb_api_key
```

Start the development server:

```bash
npm run dev
```

## React + Vite

This project uses Vite for fast development and Hot Module Replacement (HMR).

For more information, see the [Vite documentation](https://vite.dev/).
